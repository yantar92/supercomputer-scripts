This repository contains common scripts used in my work projects.
The repository is a monorepo inside supercomputer, pointing to my
data folders with scripts, simulation inputs, and simulation results.
The =.gitignore= is configured only to include files suitable for
version control (no simulation data).

* Data organization
See [[file:data-organization.org][data-organization.org]] for the full folder structure conventions
with examples and screenshots.

Summary: Folders use a =<number>.name= convention for consistent
ordering. Top-level contains =0000.scripts/= (common tools on =PATH=),
project folders (=<year>.<project name>=), and =9999.test/= for quick
experiments. Each project uses sequentially numbered steps
(=<NN>.<calculation>=), with =9999.test/= subfolders to archive
unused results away from the main calculation sequence.

* Supercomputer access
See [[file:supercomputer-access.org][supercomputer-access.org]] for full cluster details, the shared DFT
toolchain setup, VASP installation procedures (makefiles per cluster),
and personal shell/tmux configuration.

Clusters in use: Ares, Athena, Helios (PLGrid), and LUMI (CSC).
A shared group directory (=IMDGroup=) provides a common Conda
environment, VASP binaries, potentials, and helper scripts (=gorun=,
=q= alias). Each cluster has its own VASP build and =bashrc=.
