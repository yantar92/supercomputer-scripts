Result description part 2

1. Overview

  • All the VASP input files are generated using the .py scripts inside
    • Generally mpXXXXXX folders contain volume relaxation runs
    • mpXXXXX/Relax are subsequent position relaxation
    • mpXXXXX/DOS is electronic structure data
    • gorun_N_date folders contain runs computed in several iterations
      • gorun_1 is the initial iteration
      • gorun_2 is from gorun_1, and so on
      • the final iteration is the parent folder
    • overall sequence of calculations: mpXXXX/gorun_1 -> mpXXXX/gorun_2 -> … -> mpXXXX/ -> mpXXXX/Relax/gorun_1 -> … mpXXX/Relax -> mpXXX/DOS/gorun_1 -> … -> mpXXX/DOS
  • I have tweaked several INCARs to converge the results
    • in all the cases, the old INCAR is saved into INCAR.old
  • In one case, system did not converge (see below)

2. Convergence problems

  1. Did not converge in one go
    • PBERUN/IBCANDIDATES/eIBCandidate/mp27477 (volume relaxation)
    • PBERUN/IBCANDIDATES/eIBCandidate/mp27514 (volume relaxation)
    • PBERUN/IBCANDIDATES/hIBCandidate/mp29419 (volume relaxation)
  2. Converged with increased NELMIN
    • SCANRUN/IBCANDIDATES/eIBCandidate/mp19346/Relax (position relaxation)
  3. Did not converge at all
    • PBERUN/IBCANDIDATES/eIBCandidate/mp569484/DOS
      • DOS did not converge at all, everything else converged
